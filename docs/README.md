# Descenso del gradiente

## Una explicación visual para Administración de Empresas

Este GitBook presenta el descenso del gradiente como una estrategia de mejora
iterativa:

> **medir → corregir → volver a medir**

El objetivo es entender la intuición empresarial antes que memorizar una
demostración matemática. Trabajaremos con dos decisiones:

- `x`: inversión en publicidad;
- `y`: inventario de seguridad;
- `J(x, y)`: costo semanal estimado.

## Qué encontrará aquí

1. Una explicación de la idea de pendiente y gradiente.
2. Una ruta general para aplicar el algoritmo.
3. Un ejemplo empresarial completo con derivadas parciales.
4. Un laboratorio de **Python en vivo**: el código está oculto y solo se
   muestran la gráfica, la trayectoria y los controles.
